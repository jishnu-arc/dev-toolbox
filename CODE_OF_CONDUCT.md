# Code of Conduct

We want this project to be welcoming to everyone.

## Our standards

- Be respectful and patient, especially with beginners.
- Give feedback that is specific and kind.
- Accept constructive criticism gracefully.
- Harassment, insults and discrimination are not acceptable.

## Enforcement

Maintainers may edit or remove comments, commits and issues that break these standards, and may block repeat offenders. Report concerns by opening an issue or contacting the maintainer through their GitHub profile.
